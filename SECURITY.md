# Security policy

## Supported version

The latest commit on `main` is the supported portfolio reference.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature if it is enabled for this repository. Do not open a public issue containing exploit details, credentials, private infrastructure, or personal data.

Include:

- the affected file and behavior;
- a minimal synthetic reproduction;
- the expected safety property;
- any suggested remediation.

This repository intentionally contains no production credentials or endpoints. If you believe a real secret or private operational detail is present, avoid copying it and report the file path only.

## Scope

Security-relevant areas include archive extraction, path validation, receipt freshness, command construction, health URL validation, file permissions, and evidence-linking logic.

The project is a demonstration and is not a supported production recovery system.
