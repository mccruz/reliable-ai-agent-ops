# Authorship and provenance

## Public implementation

Reliable AI Agent Ops is a new public derivative written by Mark Cruz for a recruiter-facing portfolio. The code, tests, fictional service, fixtures, diagrams, and documentation in this repository were created for this package and are licensed under MIT.

## Concept provenance

The implementation is informed by independently owned operational concepts previously used in a private repository:

- timestamped readiness evidence;
- fail-closed gates;
- locked, checksummed backups;
- restore verification;
- freshness validation;
- safe external-command inputs;
- credential-free notification dry runs.

The public code expresses those concepts through a new Python package, new names, synthetic state, new receipt schemas, a new Compose topology, and new tests.

## Explicit exclusions

This repository does not include:

- private Git history or the private working tree;
- source README or authorization documentation;
- production services, hosts, users, paths, schedules, databases, images, topology, or retention settings;
- SSH, copy, launch-agent, cron, or offsite wiring;
- Telegram delivery code, destinations, tokens, messages, or logs;
- migration records, private schemas, backups, or live data;
- bundled skills, third-party source archives, or restricted dependencies.

The private concept source had no root license, so its repository was not copied or redistributed. This public derivative has its own MIT license.
